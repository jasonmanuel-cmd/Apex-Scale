## What's here

Static marketing site (no build step required):

| File | Purpose |
|------|---------|
| `index.html` | Full page: hero, interactive protocol visualizer, arbitrage matrix, ROI calculator, proof vault, FAQ, lead funnel |
| `styles.css` | Dark-luxury design system (Onyx `#06080C`, metallic gold `#D4AF37`, cyber emerald `#10B981`) |
| `app.js` | Interactive engine: canvas node graph, ROI sliders, case-study filters, 4-step qualification modal, live toasts |

## Run locally

```bash
# Any static server works
python -m http.server 3333 --directory .
# then open http://localhost:3333/
```

Or just open `index.html` in a browser.
